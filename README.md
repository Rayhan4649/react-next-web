# react-next-web

An SEO-optimized corporate website built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**, designed according to the technical documentation specification.

## 🚀 Features
- **Next.js App Router & TypeScript**: Modular, type-safe architecture.
- **Tailwind CSS v4 & Glassmorphism UI**: Modern aesthetic with Dark/Light Theme Toggle.
- **Dynamic SEO**: Automatic dynamic metadata generation (`generateMetadata`), `sitemap.xml`, and `robots.txt`.
- **API Preparation**: Static mock data scripts (`lib/mockData.ts` & `lib/services.ts`) designed for seamless Laravel REST API switching.

## 🛠️ How to Run Locally

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
